# CodeAlpha AI Submission Checklist

- [ ] Install Python 3.9 or later.
- [ ] Install the dependencies for Task 1.
- [ ] Run Task 1 and test at least two translations.
- [ ] Install the dependencies for Task 2.
- [ ] Run Task 2 and test a matching and an unrelated question.
- [ ] Capture genuine screenshots of both running applications.
- [ ] Record a short video explaining and demonstrating both projects.
- [ ] Upload the complete project folders and documentation to Google Drive.
- [ ] Set Drive sharing to "Anyone with the link — Viewer" if permitted by the programme.
- [ ] Open the copied link in a private/incognito browser window to check access.
- [ ] Complete the official CodeAlpha submission form shared in the WhatsApp group.
- [ ] Post the explanation video on LinkedIn, tag @CodeAlpha, and include the project link if required.
